# 대한민국 1인 인구이동 경로 분석

KOSIS 국내인구이동통계 자료를 바탕으로 2026년 8월 시도 간 1인 인구이동을 살펴보는 정적 웹 페이지입니다. 출발지, 도착지, 성별, 연령 조건에 따라 요약 지표와 차트, 상세 경로, 이동 행렬, 지역별 유입·유출 표를 확인할 수 있습니다.

## 구성 파일

- `index.html`: 화면 구조와 외부 CSS·JavaScript 연결
- `style.css`: 페이지 스타일
- `app.js`: 필터, 분석, 차트, 표 및 CSV 내보내기 동작
- `data.js`: 화면에서 사용하는 이동 데이터 (`RAW`, `REG`, `AGES`)
- `convert.js`: KOSIS CSV를 `data.js`로 변환하는 Node.js 스크립트
- `101_DT_1B26009_20261020142711.csv`: 변환에 사용하는 원본 CSV

## 실행

최신 브라우저에서 `index.html`을 열면 사용할 수 있습니다. 별도 패키지 설치는 필요하지 않습니다.

## CSV에서 데이터 다시 생성

Node.js가 설치된 환경에서 프로젝트 폴더에서 실행합니다.

```bash
node convert.js
```

기본 입력은 `101_DT_1B26009_20261020142711.csv`, 기본 출력은 `data.js`입니다. 다른 파일을 사용할 때는 입력 경로와 출력 경로를 인자로 지정할 수 있습니다.

```bash
node convert.js 입력.csv 출력.js
```

변환기는 CSV에서 `1인 이동자수` 항목을 골라 출발지, 도착지, 성별, 연령, 이동자수 데이터를 기록합니다. EUC-KR 및 UTF-8 인코딩을 지원합니다. 변환 후 페이지를 다시 열거나 새로고침하면 갱신된 데이터가 반영됩니다.

## 분석 기준 및 주의사항

- 출처: 국가데이터처, 「국내인구이동통계」, 2026년 8월, 「전출지/전입지(시도)/성/연령(5세)별 1인 이동건수」. 2026년 10월 20일 조회.
- [KOSIS 통계표](https://kosis.kr/statHtml/statHtml.do?orgId=101&tblId=DT_1B26009&conn_path=I2)
- 원자료의 지역 명칭을 유지합니다. `전남광주통합특별시`, `광주광역시`, `전라남도`가 함께 들어 있으므로 관련 값은 행정구역 중복 가능성을 고려해 확인해야 합니다.
- 페이지의 순유입은 지역 간 이동자수로부터 `전입 − 전출`로 계산합니다. 원자료의 `1인 순이동자수` 항목과는 구분됩니다.
- 수치는 명 단위이며, CSV에 수록된 지역 조합과 성별·연령 합계를 사용합니다.
